# Master Blog — Design Spec
**Date:** 2026-06-23
**Status:** Approved

---

## 1. Architecture

**Platform:** Hugo (static site generator — single binary, no npm, no Node)

Hugo generates static HTML from Markdown + templates. GitHub Actions builds and deploys to GitHub Pages on every push to `main`. No local Hugo installation is required to publish.

**Media hosting:**
| Media | Host | Reason |
|---|---|---|
| Podcast audio | Spotify for Podcasters | Free hosting + RSS distribution to Apple, Spotify, Amazon |
| Video | YouTube | Free CDN, embeds, global reach |
| Images | GitHub repo (`static/`) | Simple, no third party |
| Intro video | GitHub repo (`static/resource/video/`) | Short/small, self-hosted |

**Copyright:** Author retains full copyright on all content. Uploading to YouTube/Spotify grants them a distribution license only.

**URL structure:**
- `/` — homepage (all sections combined)
- `/blog/` — text articles and photo essays
- `/podcast/` — podcast episodes
- `/youtube/` — video entries
- `/sources/` — external reference links
- `/about/` — bio and profile
- `/tags/<tag>/` — auto-generated by Hugo

## 2. Content Structure & Formats

**Hugo content directories:**
```
content/
  blog/
  podcast/
  youtube/
  sources/
  about/
```

**Frontmatter schemas:**

*Blog post:*
```yaml
---
title: ""
date: YYYY-MM-DD
series: ""
episode: 1
readtime: "5 min"
image: ""        # optional
pullquote: ""    # optional
tags: []
---
```

*Podcast episode:*
```yaml
---
title: ""
date: YYYY-MM-DD
series: ""
episode: 1
duration: "42 min"
audio_url: ""
tags: []
---
```

*YouTube entry:*
```yaml
---
title: ""
date: YYYY-MM-DD
series: ""
episode: 1
youtube_id: ""
duration: ""
tags: []
---
```

*Source/reference:*
```yaml
---
title: ""
date: YYYY-MM-DD
series: ""
url: ""
tags: []
---
```

*About (single page):*
```yaml
---
title: "About Me"
profile_image: "resource/image/profile.png"
---
```

**RSS:** Hugo auto-generates `/podcast/index.xml` — this URL is submitted to Spotify for Podcasters and Apple Podcasts Connect.

**Tags:** Posts can have multiple tags. Hugo auto-generates `/tags/<tag>/` index pages.

**Note:** Frontmatter schema can be extended at any time as new needs arise.

## 3. Visual Theme & Templates

The current editorial theme is preserved exactly. Hugo templates replicate it:

```
layouts/
  _default/
    baseof.html       # shell: header, nav, dark mode, intro overlay
    list.html         # section index pages
    single.html       # individual post page
  partials/
    entry-blog.html
    entry-podcast.html
    entry-youtube.html
    entry-source.html
  index.html          # homepage (all sections combined)
static/
  css/style.css       # editorial theme CSS (moved from inline)
  js/script.js        # dark mode, nav, intro JS (moved from inline)
  resource/
    image/
    video/
```

**Theme constants (changeable at any time):**
- Font: Georgia serif body, monospace for title/nav/meta
- Palette: black/white (`#000`, `#fff`, `#ccc`)
- Dark mode: `body.dark` class, logo `filter: invert(1)` (no framing)

**Preserved from current site:**
- Intro overlay with lazy-loaded video
- Hamburger nav (mobile ≤540px)
- All `clamp()` responsive sizing
- Entry structure: tag, title, meta, cols, aside, pull quote

## 4. GitHub Actions & Deployment

Replaces current `.github/workflows/static.yml`:

```yaml
name: Deploy Hugo site
on:
  push:
    branches: [main]
jobs:
  build-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: 'latest'
      - run: hugo --minify
      - uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./public
```

- Uses built-in `GITHUB_TOKEN` — no new secrets required
- Build + deploy time: ~30 seconds after push
- `hugo --minify` compresses output HTML/CSS/JS

## 5. Migration Plan

**Branch strategy:** Build on `hugo-migration` branch, verify, then merge to `main`.

**Steps:**
1. Create branch `hugo-migration`
2. Initialize Hugo project structure
3. Copy editorial theme into Hugo templates and `static/`
4. Migrate existing placeholder content to Markdown files
5. Verify locally with `hugo server` — visual diff against live site
6. Update `.github/workflows/static.yml`
7. Merge `hugo-migration` → `main` → auto-deploy

**Assets migration:**
- `resource/image/` → `static/resource/image/`
- `resource/video/` → `static/resource/video/`
- Inline CSS → `static/css/style.css`
- Inline JS → `static/js/script.js`

**URL preservation:** Hugo configured so all current URLs remain valid.

**Rollback:** `main` retains working `index.html` until merge is confirmed good.

**Out of scope for migration:**
- Real content (placeholder content migrated as-is)
- Podcast RSS submission to platforms (done after migration)
- Gallery support (future addition)
